# Real DSH screenshots

- Captured on 2026-11-04 from the running DSH desktop application.
- `sidebar.png` shows actual balance/quota rows above the account menu. Account
  details, balances, quota percentages and reset times are covered.
- `settings.png` shows Settings → 余额与额度 → 说明 (About), including the public
  name, privacy explanation, version 1.0.0, maintainer and GitHub links.
- Cropping removes conversations and local paths; unrelated installed-plugin
  information is covered. No generated shell or replacement amounts are used.
- PNG metadata is stripped. These captures do not demonstrate live account
  verification for every adapter; see the README verification scope.

To update, capture the real DSH UI with `sh tools/capture-screenshots.sh`, then
crop or cover private information and remove PNG metadata before publishing.
